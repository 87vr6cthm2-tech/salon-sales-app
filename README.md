# SALON NOTE — 美容室の売上管理

iPhone対応の日本語売上管理アプリ。HTML / CSS / JavaScriptのみ。ビルド・依存パッケージ・サーバー不要。

## 使い方

- 初回は今月と過去2か月のダミーデータを生成します。
- 日付ごとに指名売上・フリー売上・店販売上を円単位の整数で入力。総売上と店販比率を自動計算します。
- 総売上 = 指名 + フリー + 店販。店販比率 = 店販 ÷ 総売上 × 100。総売上0円なら0.0%。
- 月セレクターか左右の矢印で切り替えます。記録をタップして編集・削除できます。同一日は1件、上書き前に確認します。
- 「ダミーデータを消去」で空の状態から実際の入力を開始できます。ダミーデータが残る間はDEMO表示されます。
- CSVは表示月を書き出します。バックアップJSONは全月のデータを保存し、「復元」で読み込めます。

## GitHub Pagesで公開

1. `index.html`、`style.css`、`app.js`、`.nojekyll`をリポジトリのルートに反映します。
2. GitHubの **Settings → Pages → Build and deployment** で **Deploy from a branch** を選択。
3. ブランチ **main**、フォルダー **/ (root)** を指定してSave。
4. 表示されたPages URLを開きます（反映には数分かかる場合があります）。

相対パスのみを使っているため、`https://USER.github.io/REPO/`でも動作します。公開するコードに売上記録は含まれません。

## ローカル起動

```sh
python3 -m http.server 8000
```

`http://localhost:8000`を開きます。ファイルを直接開くよりHTTPでの利用を推奨します。

## 保存について

データはアクセスしたURLのブラウザのlocalStorageに保存され、外部送信しません。別端末・別ブラウザ・別ドメインとは共有されません。プライベートブラウズの終了やブラウザデータの削除で消える可能性があります。定期的にJSONをバックアップしてください。保存できない場合はエラーを表示します。破損した保存データを自動上書きしません。
